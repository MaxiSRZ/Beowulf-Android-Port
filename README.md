## About

An unofficial Android port of the classic Beowulf
mobile game originally developed by Gameloft.

Ported and enhanced by **MazathStudios**, preserving
the original gameplay while improving the experience
on modern Android devices.

## ✨ Features

- Standalone Android application.
- No external emulator required.
- Up to 60 FPS interpolated rendering.
- Original, Scale2x and Scale4x graphics filters.
- Scale4x and 60 FPS enabled by default.
- Redesigned medieval-style touch controls.
- Adjustable control size and opacity.
- Original soundtrack and restored sound effects.
- Independent music and sound volume controls.
- Basic gamepad support.
- FPS counter.
- Save data backup support.
- Fullscreen landscape gameplay.

## 📱 Requirements

- Android 5.0 or newer.
- No additional emulator required.
